# cesium-sky 🌤️

> 3D weather data visualization powered by CesiumJS. Interactive demos and feature showcases.  
> CesiumJS 기반의 3D 기상 데이터 시각화 프로젝트. 주요 기능 데모 및 시연 제공.

---

## 📌 Overview (개요)

**cesium-sky**는 CesiumJS를 활용하여 다양한 기상 데이터를 3D 공간에 시각화하는 오픈소스 프로젝트입니다. 대기 흐름, 기온, 바람, 태풍 등 동적인 기상 현상을 웹 환경에서 직관적으로 탐색하고 체험할 수 있는 데모를 제공합니다.

**cesium-sky** is an open-source project designed to visualize various weather and atmospheric data in 3D space using CesiumJS. It provides interactive demos to explore dynamic weather phenomena such as wind flows, temperature, and storm tracks directly on the web.

---

## ✨ Key Features (주요 기능)

- **3D Weather Visualization**: 3D 공간 상의 실시간 및 지형 연동 기상 데이터 표현
- **Interactive Demos**: 웹 브라우저에서 직접 조작 가능한 모듈별 기능 데모
- **Video Showcases**: 주요 기능 작동 시연 영상 제공 (YouTube 연동)
